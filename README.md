# 文宣作品集｜月份文稿整理

> 公開網站與儲存庫：任何人均可瀏覽與下載本次發布的文稿、附圖、原始文章資料及網站程式碼。

## 開啟方式

解壓縮後以瀏覽器開啟 `index.html`。此版本是靜態頁面，無需安裝伺服器。

## 目前資料

- 2026 年 9 月：58 篇，含各組、文稿類別、內文與資料夾中的 72 張附圖；另有一份 PDF 附件連結。
- 勾選作品、篩選、快速跳轉及入選作品集均可使用。
- 入選清單在此瀏覽器本機保存，不會跨裝置同步。
- 「匯出入選作品 Word」產生可由 Microsoft Word 開啟的 `.doc` 文件。

## 加入其他月份

1. 需要將新月份稿件整理成同一份 JSON 資料，格式參照 `data/2026-09.json`（含 `year`、`month`、`label`、`entries`；每篇需有 `id`、`group`、`category`、`categoryNo`、`title`、`paragraphs`、`images`）。
2. 若要顯示附圖，圖片須一併放在 `assets/`，並在 `images[].src` 使用相對路徑（例如 `assets/photo.jpg`）。
3. 在網頁按「匯入月份資料 JSON」選擇該 JSON。匯入的月份僅保存於目前瀏覽器。
4. 若要讓多位組員或不同裝置共用新月份，需更新網站部署資料；僅將檔案放入 pCloud 不會自動同步至靜態網站。本機匯入不是雲端資料庫。

## 原始稿件

原始檔案保持在 pCloud 來源資料夾未經修改；網頁附件與最佳化後圖片皆為複製品。
