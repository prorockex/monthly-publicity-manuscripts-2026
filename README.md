# 文宣群島｜月份文稿審稿站

> 此 GitHub 儲存庫與 GitHub Pages 網站為公開。推送前請確認稿件、圖片、PDF 與 Drive 原始連結均已核准公開；「草稿」標記不會使公開資料變成私人資料。

## 網站入口與操作

- `index.html`：文宣群島首頁。桌面以全螢幕低多邊形 3D 群島為主視覺（滑鼠拖曳／滾輪縮放、觸控拖曳／雙指縮放、建築高亮及 CSS2D 標籤）。寬螢幕時，左右空白處是文稿導覽：左側為三組島嶼與其類別，右側為全部類別與月份總覽；連結與月份選擇器使用同一份資料，進入 `month.html` 審稿頁。頂端「隱藏導覽／顯示導覽」可收起或叫回兩側導覽，島嶼不再另外縮小成清單版面。較窄或較方的螢幕改把導覽叠在群島下方，避免擋住拖曳。首頁主結構為「三組島嶼」：三座島對應第 1／2／3 組（點島＝該組篩選），島上房子是該組在所選月份的各類別文稿（點房子＝組別＋類別篩選），中央小島為月份總覽，島民巴哥與澄瑛（兩位人物）會在島上閒晃（減少動態時靜止）。頂端可在「經典島嶼」與「天空之島」之間切換，選擇會記在這個瀏覽器。經典島嶼是海平面、斜橋與外海遊輪；天空之島是浮島、雲海與兩架玩具螺旋槳飛機，並可再切「白天／傍晚／夜晚」（路燈在傍晚與夜晚亮起）。飛機與遊輪都沒有名牌，也不能點選。側欄兩種島嶼都可使用。手機版會隱藏會擠在小畫面的 3D 標籤，但島嶼仍可點選，導覽連結仍可到達。
- `month.html`：月份審稿、同步篩選與快速跳轉頁。舊的根目錄 `index.html` 審稿網址仍會導向對應月份頁。
- 目前月份直達網址：
  - `month.html?month=2026-09`（58 篇）
  - `month.html?month=2026-10`（48 篇）
- 首頁類別／組別連結會開啟最新月份並帶入篩選條件；月份頁亦支援 `group`、`category` 與 `q` 查詢參數。

審稿狀態與意見保存在目前瀏覽器的 `localStorage`，不會跨裝置同步。標記「入選」的作品可在瀏覽器端匯出為真正的 `.docx`；請以 HTTP(S) 預覽網站以便讀取附圖並嵌入 Word。匯出內容包含作品文字、審查結果、意見與附圖，採 A4 版面。

## 本機預覽與建置

需要 Python 3 與 Node.js/npm。於專案根目錄執行：

```sh
npm ci
npm run build:site
python3 -m http.server 8000
```

瀏覽 `http://127.0.0.1:8000/`。首頁是群島，月份審稿頁為 `http://127.0.0.1:8000/month.html?month=2026-10`。`Ctrl-C` 可停止本機伺服器。建置會讀取 `data/*.json`，輸出 `index.html` 與 `month.html`；不會改寫月份 JSON。若只需要瀏覽已建置的島嶼首頁，亦可直接開啟 `index.html`；Word 附圖匯出請改用本機 HTTP 網址。Three.js 授權見 `THIRD_PARTY_NOTICES.md`。

測試：

```sh
npm test
npm run build:site
```

## 每月匯入 Google Drive 稿件

匯入器是可重現的命令列腳本 `scripts/import_drive_links.py`，不需要 Google 登入憑證。它只嘗試讀取任何人可公開讀取的 Google Docs／Drive 個別檔案；不會繞過權限。可擷取內容時會讀取標題／文字，DOCX 中的圖片會存入 `assets/`；可讀取的 PDF、純文字與圖片也會盡量擷取。若來源要求登入、無法辨識或缺少必要欄位，仍會建立保留 `driveUrl` 的草稿，並標出待補項目。

### 1. 準備連結清單

建議建立 CSV，例如 `manuscripts-2026-11.csv`：

```csv
url,group,category,categoryNo,title
https://docs.google.com/document/d/FILE_ID/edit,1,文稿,1,稿件標題
https://drive.google.com/file/d/FILE_ID/view,2,剪影,3,稿件標題
```

必要欄位只有 `url`；`group`、`category`、`categoryNo`、`title` 可留白。也可改用純文字檔，每行一個 HTTPS Docs／Drive 檔案連結。只接受個別文件或檔案網址，不接受資料夾網址。可用類別：`文稿`、`剪影`、`詩詞`、`親子園地`、`封底`。

缺少或無法推定組別時以 `group: 0`（未指定組別）呈現；類別不明時使用 `待分類`。相關項目會保留為草稿，方便人工補正。不要把未核准公開的稿件、連結或圖片推送到公開網站。

### 2. 匯入新月份

例如新增 2026 年 11 月：

```sh
python3 scripts/import_drive_links.py \
  --year 2026 --month 11 \
  --input manuscripts-2026-11.csv
```

預設會嘗試下載公開來源；每個來源預設逾時 25 秒。若只要建立保留原始連結的待補草稿、不連線讀取 Drive，可加 `--no-fetch`。結果寫入 `data/2026-11.json`，並把可擷取圖片寫至 `assets/`；命令列會列出可讀來源、草稿數與圖片數。目標月份 JSON 已存在時會拒絕覆寫；只有確認要替換時才加 `--force`（不會刪除舊圖片素材）。

### 3. 人工檢查並建置

先檢查新 JSON 中的 `draft`、`draftReason`、`group`、`category`、`categoryNo`、`title` 和 `paragraphs`。草稿提示會在審稿頁指出要補正的 `data/YYYY-MM.json`。修正欄位並確認每張圖的 `images[].src` 路徑存在；若需在瀏覽器端預覽，也確認 Drive 原稿確實准許公開存取。然後執行：

```sh
npm test
npm run build:site
```

本機以 HTTP 伺服器檢查首頁、月份切換、篩選、搜尋、審查選項、入選集及 Word 匯出。確認所有要公開的內容後，才提交並推送至此 GitHub 儲存庫；合併到 `main` 後由既有 GitHub Pages 工作流程部署。推送不等於部署完成，請在 Actions 確認 Pages 部署成功，再檢查公開網址與代表性圖片。

## 資料與部署界線

- 月份原始資料位於 `data/YYYY-MM.json`；網站頁面由建置腳本產生。請勿為了更新首頁而手動覆寫既有 JSON。
- 2026-09 與 2026-10 是既有審稿資料；任何匯入或測試均不得未經確認覆寫它們。
- 網站是靜態公開頁面。瀏覽器內的審稿決定與意見只存在於該瀏覽器，不會自動同步至 GitHub 或其他審稿者。
- pCloud 上的原始來源不會因為更新網站而被修改；上傳檔案至 pCloud 本身也不會自動更新 GitHub Pages。
