# 文宣作品集｜月份文稿整理

> 公開網站與儲存庫：任何人均可瀏覽與下載本次發布的文稿、附圖、原始文章資料及網站程式碼。

## 開啟方式

解壓縮後以瀏覽器開啟 `index.html`。此版本是靜態頁面，無需安裝伺服器。

## 目前資料

- 2026 年 9 月：58 篇，含 72 張附圖及 1 份 PDF 附件。
- 2026 年 10 月：48 篇，含 65 張附圖。
- 合計 106 篇、137 個附圖位置；十月為預設月份。
- 年份／月份切換、組別與類別同步篩選、搜尋及快速跳轉均可使用。
- 入選清單跨月份保存於目前瀏覽器；每篇可設定「待審查／入選／不入選」並填寫意見，審查狀態與意見也保存在該瀏覽器。
- 匯出入選作品會產生真正的 `.docx` 文件；作品文字、審查結果、意見及附圖都寫入同一份 Word 文件。採 A4 版面，附圖嵌入文件並依版心等比縮放，文章間分頁。
- 請從公開 HTTPS 網站匯出 Word；直接以 `file://` 開啟解壓後的 `index.html` 時，瀏覽器會限制讀取本機附圖，無法將圖片嵌入文件。
- 篩選與快速跳轉合併在固定頁首的同一個可展開面板；桌機並排顯示，手機改為上下排列，篩選結果會即時更新可點選的跳轉清單。入選作品集也可在頁首收合。

## 加入其他月份

1. 將該月份 JSON 放在 `data/`，圖片檔放在 `assets/`，並於 `images[].src` 使用相對路徑（例如 `assets/photo.jpg`）。JSON 格式參照 `data/2026-09.json`。
2. 在網站按「匯入月份 JSON」可於目前瀏覽器試看新月份；此操作不會同步給其他人。
3. 要正式更新公開網站，將新資料與圖片加入本儲存庫，執行 `python3 scripts/build_monthly_site.py`，再部署更新。建置腳本會檢查月份／稿件 ID 與圖片路徑。
4. 僅將檔案上傳到 pCloud 不會自動更新網站；入選清單仍只保存在各使用者自己的瀏覽器。

## 原始稿件

原始檔案保持在 pCloud 來源資料夾未經修改；網頁附件與最佳化後圖片皆為複製品。
